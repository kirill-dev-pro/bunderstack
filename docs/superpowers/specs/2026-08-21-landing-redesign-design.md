# Landing page redesign — dark, simplified, interactive snippets

Date: 2026-08-21
Status: approved

## Goal

Replace the light "blueprint" landing with a dark, minimal landing in the
visual language of kcrz.dev (void background, violet accent, Ubuntu Sans +
Tektur) and the structural restraint of the Elysia JS landing. Restore
interactive TypeScript hover popups (with click-to-pin) on code snippets.
Landing only — docs keep their current light fumadocs style.

## Removed (banned from the new page)

- Eyebrows / kickers / signal labels (`A / Declare`, `Backend / Bun`, `Ready / 0.18 beta`)
- Section heading duplication (aside marks A.1, B.1, …)
- SystemTrace rail + activity dots, TypeTrace bars, live-pulse animations
- Reliability stacks, story asides, comparison table, agent-context section
- All decorative lines and shapes; the only allowed decoration is one faint
  violet radial glow behind the hero

## Visual language

Tokens (from kcrz.dev `global.css`):

| Token    | Value                      |
| -------- | -------------------------- |
| void     | `#050608` page background  |
| carbon   | `#0b0d12` card surface     |
| paper    | `#f2f5f3` primary text     |
| muted    | `#92999a` secondary text   |
| accent   | `#9b7bff`, hover `#7353e6` |
| hairline | `rgba(242,245,243,0.08)`   |

Type: Ubuntu Sans Variable for body and headings (headings 800 weight,
`letter-spacing: -0.03em`, clamp sizes). Tektur Variable only for the brand
wordmark and highlighted words. Monospace stack for code and file names.

Code panels: Shiki `min-dark` theme, dark-on-dark like Elysia. Cards have no
shadows. Content column max-width ~64rem, centered.

## Page structure

1. **Nav** — brand (`⌁ bunderstack beta`) left; Docs, GitHub right; hairline
   bottom border.
2. **Hero** — centered, ~90svh: headline "Your whole backend as a single
   file.", one-sentence lede, install pill (`bun add bunderstack` + copy) and
   primary Docs button.
3. **Declaration panel** — `declaration` snippet in one centered code card;
   caption row: filename + copy button.
4. **Types reach the client** — `client` snippet plus three short bullets
   (rename a column and call sites fail; no codegen step; one error contract).
5. **Capabilities** — existing CAPABILITIES content as a 3×3 grid of plain
   cards (muted group label, title, one line).
6. **Examples** — existing EXAMPLES content as four minimal cards (label,
   path, one line).
7. **CTA band** — "Declare it once. Run it with one command." + Docs and
   GitHub buttons.
8. **Footer** — single line.

## Interactions

- Twoslash rich-hover popups (`@shikijs/twoslash/style-rich.css`, already
  imported): hovering an underlined token shows its inferred type.
- Click-to-pin restored from commit `b573ad6`: clicking a hovered token pins
  its popup open (`.twoslash-pinned`); clicking anywhere else unpins; works
  as tap on touch devices. Restore the accompanying pinned-popup CSS from
  the same era.
- Copy buttons on every code panel and the install pill (existing pattern).
- No other JavaScript. No scroll-driven or looping animation.

## Files changed

1. `website/scripts/gen-code-snippets.ts` — theme `min-light` → `min-dark`;
   snippets and integrity guards unchanged.
2. `website/src/lib/code-snippets.gen.json` — regenerated by the script.
3. `website/src/routes/index.tsx` — rewritten to the structure above;
   restores the pin hook.
4. `website/src/styles/app.css` — delete all `blueprint-*`, trace, signal,
   story, reliability, comparison landing styles; add dark landing styles.
   Base and docs rules stay untouched.
5. `website/package.json` — add `@fontsource-variable/ubuntu-sans`,
   `@fontsource-variable/tektur`; import fonts in the landing route.

## Verification

- `cd website && bun run build` passes: twoslash type-checks every snippet,
  prerender completes.
- Rendered HTML contains no banned classes (`system-trace`, `type-trace`,
  `section-heading__signal`, `blueprint-kicker`).
- Manual pass in `bun run dev`: hover popup appears, click pins/unpins, copy
  buttons work, mobile layout holds one column.

## Out of scope

Docs theming, MDX content, examples' own pages, SEO metadata beyond keeping
the existing title/description current.
