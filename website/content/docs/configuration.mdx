# Configuration

## Options

```ts
import { libsql } from 'bunderstack/database/libsql'
import { smtp } from 'bunderstack/email/smtp'

await createBunderstack({
  schema,
  database: {
    adapter: libsql(),
    url?: string,
    authToken?: string,
    migrations?: string, // migrations folder, default './migrations'
  },
  access?: Record<string, {
    crud?: boolean,
    ownerColumn?: string,
    list?: 'public' | 'authenticated' | 'owner' | 'deny',
    get?: 'public' | 'authenticated' | 'owner' | 'deny',
    create?: 'public' | 'authenticated' | 'owner' | 'deny',
    update?: 'public' | 'authenticated' | 'owner' | 'deny',
    delete?: 'public' | 'authenticated' | 'owner' | 'deny',
    writableColumns?: string[],
    readonlyColumns?: string[],
  }>,
  auth?: BetterAuthConfig, // native BetterAuth options (except database) — see better-auth.com/docs
  storage?: {
    local?: string | true,
    s3?: true | { endpoint?: string },
    defaultBucket?: string,
    buckets?: Record<string, {
      upload?: { maxSize?: string | number, accept?: string[] },
      transforms?: boolean,
      access?: { create?: OperationRule, get?: OperationRule, delete?: OperationRule },
    }>,
  },
  email?: {
    from: string,
    provider?: 'resend' | 'console' | EmailAdapter | EmailAdapter['send'],
  },
  env?: {
    server?: Record<string, ZodType>,  // must NOT start with PUBLIC_
    client?: Record<string, ZodType>,  // MUST start with PUBLIC_
    runtimeEnv?: Record<string, unknown>, // browser value source (Vite's import.meta.env)
  },
  trpc?: ((t: BunderstackTRPC) => AnyRouter) | AnyRouter, // builder callback or prebuilt router
  rateLimit?: boolean | RateLimitConfig,
  idempotency?: boolean | IdempotencyConfig,
  realtime?: boolean | {
    keepaliveMs?: number,
    bufferSize?: number,
    redis?: string | { url: string; token?: string },
  },
  jobs?: (j: BunderstackJobsBuilder) => JobsDefs,
})
```

## Realtime transport

| Configuration | Selected transport | Intended use |
| --- | --- | --- |
| Realtime omitted or `false` | `disabled` | No SSE subscriptions or publications |
| `realtime: true` | `memory` | One process, including an embedded worker |
| `realtime: true` + `REDIS_URL` | `redis` | Separate web and worker processes |
| `realtime: { redis: "redis://…" }` | `redis` | Explicit shared broker URL |
| `realtime: { redis: { url, token } }` | `redis` | Shared broker with a token |

The web server and every standalone worker must use the same Redis instance
when job handlers call `ctx.realtime.publish()`. Memory transport is
process-local: an event published in the worker cannot reach a browser
subscribed through another process.

Since 0.9.0, `app.runWorker()` fails at startup when it detects memory
transport. Use `app.startWorker()` to embed the worker, configure Redis, or pass
`allowProcessLocalRealtime: true` only when job handlers never publish
realtime events.

At runtime, inspect `app.realtime.transport`. During deploy introspection,
`app.manifest.realtimeTransport` reports the configured transport without
opening a Redis connection.

## Database adapters and URLs

Import exactly one adapter from `bunderstack/database/<adapter>`. Its dialect
must match the schema (`sqliteTable` for libSQL; `pgTable` for the Postgres
adapters). The schema dialect, not the adapter, selects the default URL:
SQLite defaults to `file:./data.db` and Postgres defaults to the local PGlite
path `file:./data.pglite`.

| Adapter import                                      | Optional peer to install      | URLs                                                           |
| --------------------------------------------------- | ----------------------------- | -------------------------------------------------------------- |
| `bunderstack/database/libsql` (`libsql()`)          | `@libsql/client`              | SQLite's default `file:./data.db`; `libsql://…` for Turso      |
| `bunderstack/database/pglite` (`pglite()`)          | `@electric-sql/pglite`        | Postgres's default `file:./data.pglite`; `memory://` for tests |
| `bunderstack/database/bun-sql` (`bunSql()`)         | none — Bun provides `Bun.sql` | explicit `postgres://…` URL required                           |
| `bunderstack/database/postgres-js` (`postgresJs()`) | `postgres`                    | explicit `postgres://…` URL required                           |

Install only the selected adapter's peer. `DATABASE_URL` (or `database.url`)
supplies its URL; Bun SQL and postgres.js require an explicit Postgres URL
because the Postgres dialect default is a local PGlite path. An incompatible
adapter/schema pair or URL fails at startup.

## SMTP

SMTP is an explicit email adapter rather than an `email.provider` string. Add
Nodemailer only when using it, then pass the factory result. Do not assign the
old `'smtp'` string to `email`; `email: smtp(...)` also omits the required
sender. Keep the email config and use the factory as `provider`:

```ts
email: {
  from: 'My app <hello@example.com>',
  provider: smtp({ url: process.env.SMTP_URL! }),
}
```

## Introspection and lifecycle

Set `BUNDERSTACK_INTROSPECT=1` to load a manifest without connecting to a
database. The selected adapter returns `drizzle.mock({ schema })`, so no
database client is created; Redis is also skipped. Real PGlite, libSQL,
postgres.js, and Bun SQL clients are owned by the app and closed by
`await app.close()`.

## Environment variables

| Variable                  | Default                                               | Description                                          |
| ------------------------- | ----------------------------------------------------- | ---------------------------------------------------- |
| `DATABASE_URL`            | `file:./data.db` (sqlite) / `file:./data.pglite` (pg) | Connection string — see the table above              |
| `DATABASE_AUTH_TOKEN`     | —                                                     | Turso auth token                                     |
| `AUTH_SECRET`             | dev default                                           | BetterAuth secret — required in production           |
| `REDIS_URL`               | —                                                     | Shared realtime broker for separate web/worker processes |
| `RESEND_API_KEY`          | —                                                     | Required when email provider is 'resend'             |
| `SMTP_URL`                | —                                                     | SMTP connection URL passed to `smtp({ url })`        |
| `S3_BUCKET`               | —                                                     | S3 bucket name                                       |
| `S3_REGION`               | `us-east-1`                                           | S3 region                                            |
| `S3_ACCESS_KEY_ID`        | —                                                     | S3 access key                                        |
| `S3_SECRET_ACCESS_KEY`    | —                                                     | S3 secret                                            |
| `S3_ENDPOINT`             | —                                                     | Custom endpoint for R2 / MinIO                       |
| `BUNDERSTACK_CRON_SECRET` | —                                                     | Required in production for signed scheduled delivery |
